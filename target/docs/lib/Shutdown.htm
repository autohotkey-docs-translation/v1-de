Shutdown

Fährt das System herunter, startet es neu oder meldet es ab.

Shutdown, Flags

Parameter

Flags

Eine Kombination (oder Summe) von Nummern aus der Tabelle unten, die den Shutdown-Typ angibt.

Dieser Parameter kann ein Ausdruck sein.

Shutdown-Typen

Nummer Windows-Konstante Beschreibung
0x0 (0) EWX_LOGOFF Schließt alle Prozesse und meldet danach den Benutzer ab.
0x1 (1) EWX_SHUTDOWN Fährt das System so weit herunter, dass die Stromversorgung sicher unterbrochen werden kann. Alle Dateipuffer werden auf die Festplatte geflusht, und alle laufenden Prozesse werden beendet. In Windows XP SP1 oder höher wird anschließend die Stromversorgung unterbrochen, sofern das System das Power-Off-Feature unterstützt.
0x2 (2) EWX_REBOOT Fährt das System herunter und startet es danach neu.
0x4 (4) EWX_FORCE Erzwingt das Schließen aller geöffneten Anwendungen. Dies sollte nur im Notfall verwendet werden, da es zu Datenverlust bei allen geöffneten Anwendungen führen kann.
0x8 (8) EWX_POWEROFF Fährt das System herunter und unterbricht die Stromversorgung. Das System muss das Power-Off-Feature unterstützen.
0x400000 (4194304) EWX_HYBRID_SHUTDOWN Bereitet das System auf den Schnellstart vor, fährt das System herunter und unterbricht die Stromversorgung. Benötigt Windows 8 oder höher, und die entsprechende Option muss in den Energieeinstellungen des Systems aktiviert sein (sofern verfügbar).

Bemerkungen

Addieren oder kombinieren Sie die gewünschten Werte. Zum Beispiel können Sie 9 (1 + 8) angeben, um das System herunterzufahren und die Stromversorgung zu unterbrechen. Alternativ können Sie einen Ausdruck wie 1 + 8 oder 0x1 | 0x8 angeben.

Um das System anzuhalten oder in den Ruhemodus zu versetzen, siehe Beispiel #2 am Ende dieser Seite.

Um den Monitor auszuschalten, siehe PostMessage-Beispiel #1.

Ein Skript kann auch OnExit verwenden, um zu erkennen, wann das System herunterfährt oder der Benutzer sich abmeldet.

Beispiele

Erzwingt einen Neustart (Neustart + Erzwingen = 2 + 4 = 6).

Shutdown, 6

Ruft die Windows-API-Funktion "SetSuspendState" auf, um das System anzuhalten oder in den Ruhemodus zu versetzen. Beachten Sie, dass der zweite Parameter auf neueren Systemen möglicherweise überhaupt keine Wirkung hat.

; Parameter #1: 1 statt 0 übergeben, um den Ruhemodus statt Anhalten zu bewirken.
; Parameter #2: 1 statt 0 übergeben, um Anhalten ohne Nachfrage zu erzwingen.
; Parameter #3: 1 statt 0 übergeben, um alle Aufwachereignisse zu deaktivieren.
DllCall("PowrProf\SetSuspendState", "Int", 0, "Int", 0, "Int", 0)
